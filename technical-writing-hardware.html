Hardware Technical Writing

This page showcases a diverse range of hardware documentation, from medical-grade refrigeration units to household appliances and consumer electronics. Primarily featuring my work as a Technical Writer for Felix Storch, Inc. (across brands like Summit, EQTemp, and MOMCUBE), these samples include user manuals, installation guides, and ADA-compliance instructions.

EQTemps Vaccine Refrigerator User Manual

Specialized manual for a vaccine refrigerator, focusing on temperature monitoring, alarm systems, and CDC storage requirements.

This documentation ensures that medical professionals can maintain strict temperature controls necessary for vaccine viability, following industry standards and safety protocols.

Handle Installation Instruction Sheet

Step-by-step installation guide for a stainless steel appliance handle, including required tools and mounting procedures.

Instruction Manual for ADA-Compliant Range Hoods

Essential user manual for an ADA-compliant range hood, featuring operating instructions, filter replacement guides, and cleaning tips.

Breast Milk Freezer

Comprehensive user manual for a medical-grade breast milk freezer, covering safety protocols, installation, and temperature management.

InnoGear Aromatherapy Diffuser User Manual

Identified and resolved translation murkiness and organizational issues in an existing guide. Rewrote instructions to be more intuitive and optimized the layout for better user comprehension.

Frost-Free Warming and Cooling Drawer User Manual

User manual for the SPHC30/36 dual-function warming and cooling drawer, detailing temperature control, Sabbath mode, and installation.

Remote Switch Installation for ADA Compliant Wall Mounted Range Hoods

Installation guide for a remote switch on ADA-compliant wall-mounted range hoods, specifying mounting height and wiring requirements.

ADA Conversion (ADRD18H34)

Instructions on converting the ADRD18H34 refrigerator to meet ADA compliance standards using a remote switch.

PNR Installation Instructions

Instructions on installing custom overlay panels on PNR series appliances, including panel dimensions and hinge adjustments.
