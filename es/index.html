Redactor técnico. Redactor UX. Diseñador de contenido.

De verdad me encantan las palabras.



Por años, mi carrera profesional se ha centrado en un objetivo fundamental: desmitificar conceptos complejos para el público general. Ya sea como tutor, periodista o redactor técnico, mi enfoque siempre es crear contenido accesible y comprensible.

Este portafolio reúne trabajos destacados de cada faceta: artículos de divulgación, documentación técnica (manuales de usuario para hardware y software, y guías de APIs) y proyectos de redacción UX. Diseñé estos ejemplos con herramientas como Swagger y Postman para ilustrar flujos de desarrollo claros, funcionales y bien estructurados.

Documentación técnica: Arquitectura de observabilidad en la nube y para IA

Diseñé una suite documental integral para un pipeline dual de observabilidad. El sistema integra Datadog para ingesta de registros y Galileo para la trazabilidad de modelos LLM e inteligencia artificial. El proyecto incluye modelos conceptuales, referencias de API para ingesta en streaming y guías prácticas para enrutar telemetría mediante procesadores nativos de la nube.

Desarrollado bajo el paradigma Docs-as-Code con Docusaurus y Markdown. Cuenta con diagramas interactivos en Mermaid y ASCII que ilustran con precisión los flujos concurrentes de datos y la arquitectura técnica del sistema.

Trabajos seleccionados

Muestra de documentación: SDK de TypeScript para Sui

Guía práctica y completa para desarrolladores sobre cómo consultar y registrar transacciones en la blockchain de Sui con el SDK de TypeScript. Incluye conceptos clave, tutoriales paso a paso y páginas de referencia de API para interactuar con objetos de SuiClient.

Muestra de documentación: API de Stripe

Documentación de API REST desarrollada en Markdown con VS Code y validada con Vale. Endpoints verificados en Postman, arquitectura de autenticación detallada y control de versiones en GitHub Wiki. Demuestra un flujo de trabajo profesional de Docs-as-Code para desarrolladores.

Flujo de incorporación para aplicación bancaria

Flujo de onboarding completo para una aplicación de finanzas personales. Diseñado para generar confianza y guiar al usuario paso a paso en la automatización de pagos, cumpliendo estrictas restricciones de espacio y tono.

Manual de usuario: Difusor de aromaterapia InnoGear

Optimización integral de una guía de usuario con deficiencias estructurales y de traducción. Reescritura de instrucciones con lenguaje directo y rediseño visual enfocado en facilitar la comprensión inmediata.

Manual de usuario: Refrigerador para vacunas

Manual especializado para refrigeradores de vacunas de grado médico. Centrado en protocolos de monitoreo térmico, configuración de alarmas y normativas de almacenamiento de los CDC.

Recordkeeping

Un sitio web que desarrollé con HTML, Bootstrap y JavaScript para catalogar mi colección personal de discos de vinilo.

Educación en la República Dominicana

Parte de una serie de artículos que escribí sobre los Objetivos de Desarrollo Sostenible de la ONU en la República Dominicana.

Manual de usuario: Congelador de leche materna

Manual técnico y de operación para congeladores de leche materna de grado médico, con énfasis en bioseguridad, calibración de temperatura e instalación.

Cajón térmico y de enfriamiento sin escarcha

Manual de usuario para el cajón térmico y refrigerador SPHC30/36. Incluye instrucciones de control de temperatura, configuración de modo Sabbath y procedimientos de instalación.
