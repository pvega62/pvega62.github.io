Technical Writer. UX Writer. Journalist.

I just really like words.



For years, my professional career has centered on one core goal: demystifying complex concepts for the general audience. Whether as a tutor, a journalist, or a technical writer, my focus is always on creating accessible and understandable content.

This portfolio showcases different pieces from each area. You'll find some articles and essays, technical documentation (e.g., user guides for hardware and software, API documentation), and UX writing samples. These samples were created using different platforms like Swagger and Postman and showcase instructions for using those platforms to get the intended results.

Cloud and AI Observability Pipeline Documentation

Built a multi-layered documentation suite for a dual-track observability pipeline, integrating Datadog for cloud log ingestion and Galileo for AI/LLM tracing. This project features conceptual models, a streaming ingest API reference, and a hands-on guide for routing telemetry through cloud-native processors.

Executed using a modern Docs-as-Code workflow with Docusaurus and Markdown, featuring Mermaid and ASCII diagrams to illustrate the concurrent data streams and "two-track" architecture of modern cloud and AI observability.
