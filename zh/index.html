技术写作者。UX 写作者。内容设计者。

我只是由衷地热爱文字。



多年来，我的工作重点一直是将复杂的概念转化为通俗易懂的内容供大众阅读。作为一名教育工作者、记者和技术写作者，清晰、引人入胜且易于理解的内容始终是我的首要追求。

本作品集收录了我在这些领域的代表作品：已发表的文章、技术文档（涵盖硬件与软件用户指南，以及 API 参考资料）和 UX 写作样本。这些内容运用 Swagger 和 Postman 等先进工具开发，旨在为开发人员和终端用户提供端到端的工作流程与卓越体验。

云与 AI 可观测性数据管道文档

为双轨可观测性数据管道构建了多层级文档套件，整合了用于云日志摄取的 Datadog 与用于 AI/LLM 追踪的 Galileo。该项目包含概念模型、流式摄取 API 参考，以及通过云原生处理器路由遥测数据的实操指南。

采用基于 Docusaurus 和 Markdown 的现代 Docs-as-Code（文档即代码）工作流构建。通过 Mermaid 和 ASCII 图表清晰展示并发数据流与双轨可观测性架构。

精选作品

TypeScript SDK Sui 文档样本

创建了详尽的文档样本，指导开发人员如何使用 TypeScript SDK 在 Sui 区块链上读写数据。该套件包含概念指南、教程以及围绕查询和交互 SuiClient 对象数据的 API 参考页面。

Stripe API 文档样本

使用 VSCode 编写 Markdown 格式的 REST API 文档，并使用 Vale 进行风格与语法检查。通过 Postman 验证端点，记录身份验证流程，并在 GitHub Wiki 中进行维护，充分展现端到端开发者文档工作流。

银行应用新用户引导流程

本样本展示了金融应用的完整新用户引导流程。在遵守严格技术约束条件的同时，通过自信、清晰且专业的语气建立用户信任。

InnoGear 香薰机用户手册

识别并解决了现有指南中存在的翻译模糊和结构混乱问题。重写了操作说明以提升直观性，并优化了排版布局，更便于用户理解。

疫苗冷藏箱用户手册

专为疫苗冷藏箱编写的专业用户手册，重点涵盖温度监控、报警系统以及美国疾控中心（CDC）的存储规范要求。

Recordkeeping

一个使用 HTML、Bootstrap 和 JavaScript 构建的个人黑胶唱片收藏目录网站。

多米尼加共和国的教育

关于联合国在多米尼加共和国推进的可持续发展目标（SDGs）系列深度撰文之一。

母乳冷冻箱用户手册

医用级母乳冷冻箱综合用户手册，涵盖安全规范、设备安装及温度管理指南。

无霜保温冷藏抽屉

ACME SPHC30/36 双功能保温冷藏抽屉用户手册，详细阐述了温度控制、安息日模式与安装规范。
