كاتب تقني. كاتب تجربة المستخدم. مصمم محتوى.

أنا ببساطة شغوف بالكلمات.



لسنوات عديدة، ركزت في عملي على تبسيط المفاهيم المعقدة وشرحها للجمهور. وبصفتي معلماً وصحفياً وكاتباً تقنياً، كنت دائماً أضع في مقدمة أولوياتي إنشاء محتوى واضح وجذاب وسهل الفهم.

يضم هذا الملف نماذج متنوعة من أعمالي في هذه المجالات: مقالات منشورة، ووثائق تقنية (أدلة مستخدم للأجهزة والبرمجيات، بالإضافة إلى مراجع واجهات برمجة التطبيقات API)، ونماذج لكتابة تجربة المستخدم UX. وقد طورت هذه النماذج باستخدام أدوات متقدمة مثل Swagger وPostman لتقديم مسارات عمل متكاملة وواضحة للمطورين والمستخدمين على حد سواء.

توثيق خط أنابيب مراقبة السحابة والذكاء الاصطناعي

أنشأت مجموعة وثائق متعددة الطبقات لخط أنابيب مراقبة مزدوج المسار، يدمج Datadog لاستيعاب سجلات السحابة وGalileo لتتبع نماذج الذكاء الاصطناعي/LLM. يضم المشروع نماذج مفاهيمية ومرجع API لاستيعاب البث ودليلاً تطبيقياً لتوجيه بيانات القياس عبر معالجات السحابة الأصيلة.

بُني باستخدام سير عمل Docs-as-Code الحديث مع Docusaurus وMarkdown. توضح المخططات بتنسيقَي Mermaid وASCII تدفقات البيانات المتزامنة وبنية المراقبة المزدوجة.

أعمال مختارة

نموذج توثيق حزمة TypeScript SDK لـ Sui

أنشأت نموذج توثيق شاملاً يُعلّم المطورين كيفية قراءة البيانات وكتابتها على بلوكتشين Sui باستخدام حزمة TypeScript SDK. يضم الملف دليلاً مفاهيمياً وبرنامجاً تعليمياً وصفحات مرجعية لـ API تمحورت حول الاستعلام عن بيانات كائن SuiClient والتفاعل معها.

نموذج وثائق واجهة برمجة تطبيقات Stripe

كتبت وثائق REST API بتنسيق Markdown في VSCode مع التحقق منها باستخدام Vale. تحققت من نقاط النهاية باستخدام Postman، ووثقت تدفق المصادقة، وأدرت الوثائق في GitHub Wiki. يُظهر النموذج سير عمل توثيق المطورين الكاملة من البداية إلى النهاية.

مسار تهيئة وبدء الاستخدام لتطبيق مصرفي

يعرض هذا النموذج مسار تهيئة شاملاً لتطبيق مالي، ويُبرز القدرة على بناء ثقة المستخدم بأسلوب واثق وواضح واحترافي مع الالتزام بالقيود التقنية الصارمة.

دليل مستخدم جهاز توزيع الروائح InnoGear

رصدت مشكلات الترجمة الركيكة والتنظيم غير المنهجي في الدليل الأصلي وعالجتها. أعدت كتابة التعليمات لتكون أكثر سهولة وبديهية، وحسّنت تصميم الصفحة لتعزيز فهم المستخدمين.

دليل مستخدم ثلاجة حفظ اللقاحات

دليل مستخدم متخصص لثلاجة حفظ اللقاحات، يركز على مراقبة درجات الحرارة وأنظمة الإنذار ومتطلبات تخزين مركز السيطرة على الأمراض والوقاية منها (CDC).

Recordkeeping

موقع إلكتروني بنيته باستخدام HTML وBootstrap وJavaScript لحفظ فهرس مجموعتي الشخصية من الأسطوانات الفينيلية.

التعليم في جمهورية الدومينيكان

جزء من سلسلة مقالات كتبتها حول أهداف التنمية المستدامة للأمم المتحدة في جمهورية الدومينيكان.

دليل مستخدم فريزر حفظ حليب الأم

دليل مستخدم شامل لمجمّد حليب الأم بمواصفات طبية، يغطي بروتوكولات السلامة وإجراءات التركيب وإدارة درجات الحرارة.

درج التدفئة والتبريد المقاوم للتجمد

دليل مستخدم لدرج التدفئة والتبريد المشترك ACME SPHC30/36، يوضح التحكم بدرجات الحرارة ووضع السبت (Sabbath mode) وإجراءات التركيب.
